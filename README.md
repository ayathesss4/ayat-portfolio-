# Ayat Hassan — Portfolio

React + Vite + Tailwind CSS portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview   # optional, preview the production build locally
```

## Before deploying — things to update

The design brief didn't include real contact details or project screenshots,
so these were left as clearly-labeled placeholders:

- `src/components/Contact.jsx` and `src/components/Footer.jsx` — replace
  `EMAIL`, `LINKEDIN`, and `GITHUB` with your real links.
- Project preview panels currently use a styled "browser window" placeholder
  (name + category) instead of real screenshots. If you'd like actual
  screenshots, add images under `src/assets/` and swap them into
  `src/pages/ProjectDetails.jsx`.
